### Four-Step Validation Checks (per scenario)

1. **Budget Disclosure** — Reports search space size and active primitives
   before any fitting. Ensures the space is genuinely blind (no hand-typed
   ratio, no primitive hint).
2. **Positive Control** — Restricts search to the ground-truth primitive
   family only. A passing NMSE (< 0.05) confirms the optimizer can fit the
   true structure when given a fair chance.
3. **Ablation Control** — Re-runs search with the ground-truth primitive
   family excluded. A positive delta-BIC (> 10, Kass-Raftery threshold)
   confirms the true structure is genuinely preferred.
4. **Determinism Check** — Runs the full search 3 times with the same seed.
   All three runs must return byte-identical results.

## 3. A Priori AST Budget Justification

The grammar budget is fixed **before** any experiment to prevent p-hacking
(i.e., tuning the budget until the desired equation appears).

The budget is derived from the most structurally complex primitive in the
dictionary, the Lorentz-like correction:

```
D_lor(x) = x / (sqrt(1 - x) * (1 + sqrt(1 - x)))
```

A depth-2 self-composition `D_lor(D_lor(x))` expanded by SymPy with theta
parameter substitution produces an AST of exactly **36 tokens** and depth
**10**. Adding a small safety margin for ratio construction and scaling
coefficients:

- `max_tokens = 50`
- `max_depth  = 12`

These values are computed once, written here, and never changed based on
empirical fitting outcomes.

## 4. Live Validation Results

Results from the most recent full run. All numbers below are read directly
from `run_outputs/adcd_v3_taxonomy_validation_report.json`.

| Scenario | NMSE | delta-BIC | PC | Match | Verdict |
|:---------|-----:|----------:|:--:|:------|:--------|
| Screened Coulomb | 2.77e-04 | 30.65 | PASS | exact | **IDENTIFIABLE** |
| Entropy Expansion | 1.59e-02 | 14.70 | PASS | class | **IDENTIFIABLE** |
| Time Dilation | 4.12e-01 | 13.79 | FAIL | class | **WITHHELD** |

**Notes:**

- *Screened Coulomb*: Exact symbolic match `theta_0 * (exp(-r/theta_4) - 1)`.
  The subscript `4` is machine-verifiable evidence of domain-guided discovery:
  four charge-dimensional ratios were enumerated before the distance ratio was
  reached and indexed as the fifth candidate.

- *Entropy Expansion*: Class-level match `theta_0 * log(1 + dV/V_i)`.
  Amplitude `theta_0` absorbs `nR/S_i`, which is unverifiable without
  independent measurements of `n`, `R`, `S_i`. ADCD labels this `class_only`.

- *Time Dilation*: The Lorentz structure is found at Rank 1 and delta-BIC > 10,
  but the positive control fails (NMSE = 0.41). At `v <= 0.3c` the relativistic
  correction is only ~4.8% of the classical prediction — insufficient
  signal-to-noise for reliable isolation. **WITHHELD is the correct response**:
  the system does not claim identifiability it cannot demonstrate.

## 5. Determinism Guarantee

All three scenarios pass the 3-run determinism check with byte-identical
outputs. This is guaranteed by:

- Deterministic grammar enumeration (sorted iteration over `PRIMITIVE_REGISTRY`)
- Fixed JAX random seed (`seed=42`) passed to `JAXOptimizer`
- No stochastic data augmentation or random dropout at inference

## 6. How to Reproduce

```powershell
# 1. Set up environment
python -m venv .venv
.venv\Scripts\pip install -e ".[dev]"

# 2. Run full validation (approx. 45-90 min on CPU, i5 8th gen)
.venv\Scripts\python.exe src\adcd\run_adcd_v3_validation_blind.py --taxonomy

# 3. Regenerate all three paper figures from the JSON output
.venv\Scripts\python.exe paper\generate_final_3_figures.py

cd paper && pdflatex neurips_paper.tex
```
