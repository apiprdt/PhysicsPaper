# ADCD Pre-Registration Hypotheses Lock
# Timestamp: 2026-07-31

Primary Hypothesis (H1):
Physics-gate post-filtering of symbolic regression candidates — via dimensional homogeneity check, complexity bound, and Asymptotic Recovery Constraint (ARC) — significantly reduces the false positive rate (FPR) on noisy physical dataset benchmarks compared to unfiltered search engines, across all evaluated search algorithms.

Secondary Hypothesis (H2):
Under a correction-first formulation (fitting residual delta(x) = y - f0(x)), physics-gate post-filtering achieves a higher valid recovery rate (VRR) of physically consistent target expressions than standard unconstrained symbolic regression (fitting target y directly), particularly under moderate-to-high noise regimes (sigma >= 0.05).

Null Hypothesis (H0):
Physics-gate post-filtering provides no statistically significant reduction in false positive rate (p >= 0.05 via Wilcoxon signed-rank test) and no improvement in valid recovery rate across benchmark test cases.
