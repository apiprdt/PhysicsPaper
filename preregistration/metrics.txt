# ADCD Pre-Registration Metrics Lock
# Timestamp: 2026-07-31

M1: Physical Validity Rate (PVR)
Definition: PVR = |{candidates passing all physics gates}| / |{total candidates evaluated}|
Range: [0.0, 1.0]. Higher indicates higher physics filtering selectivity.

M2: False Positive Reduction Rate (FPRR)
Definition: FPRR = (FP_unfiltered - FP_filtered) / FP_unfiltered
Where FP (False Positive) is a candidate with low numerical training error (NMSE < 0.05) that violates at least one physics constraint (dimensional inconsistency, depth/complexity violation, or non-zero asymptotic residual limit as x -> x_classical).

M3: Valid Recovery Rate (VRR)
Definition: VRR = |{valid candidate expressions with tree edit distance < 0.4 from ground truth}| / |{total valid candidates}|
Tree edit distance calculated via standard Zhang-Shasha AST comparison.

M4: Correction-First Gain (CFG)
Definition: CFG = VRR_correction_first - VRR_direct_fitting
Evaluated on Level B synthetic correction scenarios across noise levels sigma in {0.01, 0.05, 0.15}.
